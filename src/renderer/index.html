    聊天

    聊天分頁專用，與翻譯的雲端設定各自獨立（翻譯可用便宜模型、聊天用強模型）。 可設多組供應商、各自帶獨立的模型清單。系統提示改在聊天頁的工具列切換與管理。

    以下欄位屬於目前選取的供應商。

    OpenAI 相容 chat completions 端點

    聊天頁可即時切換清單中的模型。「掃描模型」會先儲存供應商設定， 再向該供應商的 /models 端點取得可用清單。

    語音轉文字

    檔案轉錄與即時字幕共用。本地為 Qwen3-ASR；雲端走 OpenAI 相容 transcriptions API。

    本地 ASR

    請在「模型」下載 Qwen3-ASR-0.6B。全程離線。

    本地 ASR 只跑 CPU：官方 sherpa-onnx 的 Windows 套件未編譯 GPU 支援， 指定 CUDA／DirectML 會被靜默退回 CPU。需要 GPU 級速度請改用上方的「雲端」。 執行緒不是越多越好，不確定就留「自動」。

    雲端 ASR

    需支援 /audio/transcriptions

    例如 openai/whisper-1、 openai/whisper-large-v3。 STT 模型列表
