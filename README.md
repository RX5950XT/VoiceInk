# VoiceInk

Windows 桌面 AI 工作台。**聊天**、**終端機**、**本機大型語言模型**（HF模型）、**訂閱額度**、**AGY 反向代理**、**語音轉文字**（檔案轉錄／即時字幕／全域語音輸入）、**翻譯與 TTS** 放在同一個 App；語音相關功能可完全離線（本地模型、CPU 即時），也能改走雲端 API。

**v1.11.0** — [下載安裝檔](https://github.com/RX5950XT/VoiceInk/releases)

本版新增**管理員終端機**：開新終端機時勾「以系統管理員身分執行」，就在 App 裡拿到提權的 shell
（UAC 只在當次第一個管理員終端機跳一次）。

前一版帶來**全域語音輸入**（按住右 Alt 講話，放開就把整理好的文字貼進你正在用的程式）、
**系統監控**（含免提權硬碟健康度、壓力測試與風扇控制）、**HF模型**（從 Hugging Face 抓 GGUF 直接在聊天裡用）。

## 功能

### 聊天

走 OpenAI 相容端點的多會話聊天，可同時掛多組供應商。

- **多組供應商**：每組帶自己的 API URL／Key／模型清單，模型下拉依供應商分組，切換即用
- **模型掃描**：向該供應商的 `/models` 掃一遍，勾選要留的加進清單（OpenRouter 一次回三百多個，所以預設一個都不勾）
- 逐字串流、可隨時停止；中斷前收到的內容照樣存檔
- 圖片輸入：貼上／拖放／選檔，最多 4 張，送出前縮到長邊 1568px
- 生圖模型：在設定的模型清單把那一顆勾「生圖」，聊天頁選到它（選單會標 🖼）就會回圖片，存在本機、跟著對話一起留著
- 思考開關：開啟才帶 `reasoning_effort`，模型回傳的思考過程以可摺疊區塊呈現
- 系統提示可存多組，在輸入框那一排即時切換與管理
- 每則訊息可複製，最後一則回覆可重新生成
- Markdown 為自寫渲染器（零 `innerHTML`、零第三方套件），程式碼區塊附複製鈕

**側欄**負責整理對話：搜尋、就地改名、逐列刪除（按鈕自己變紅勾的二次確認，不開原生彈窗）、抓著就能拖曳排序（也支援 Alt+↑／↓）。訊息串上方沒有工具列——系統提示與模型選單都在輸入框那一排。

聊天與翻譯**共用同一份供應商清單**（都是 OpenAI 相容的 chat completions，沒必要把同一組網址金鑰填兩次）；至於各自要用哪一顆模型，在各自的頁面上選——翻譯挑便宜快的、聊天挑強的，互不干擾。

### 終端機

側欄可以同時開好幾個工作階段，每個都是一顆獨立的 shell——同時跑三個 AI 代理，一眼就知道哪個還在忙、哪個跑完了。

- **側欄顯示運行狀態**：`運行中`／`已完成`（指令失敗會多顯示離開碼）／`已結束`
- **跑完會亮未讀點**：跑完的當下你不在看那一個，它就亮著等你，點進去自動清掉
- **新終端機可選啟動指令**：純 shell、Claude Code、Codex，開好直接跑起來
- **記住工作目錄**：每個階段各自記著自己的資料夾，重開 App 之後點一下就從同一個地方接著開
- Shell 可選 PowerShell 7／Windows PowerShell／命令提示字元（沒裝的會標示出來）
- **以系統管理員身分執行**：勾了就開提權的 shell，側欄那一列會標「管理員」；
  UAC 只在當次第一個管理員終端機跳一次，關掉 App 時提權的 shell 會一起收乾淨
- 側欄一樣可以就地改名、逐列刪除（按鈕變紅勾的二次確認，不開原生彈窗），抓著就能拖曳排序（也支援 Alt+↑／↓）

關掉視窗縮到系統匣時，這些 shell **會繼續跑**——長時間的代理任務不會因為關視窗而中斷。

> 「運行中／已完成」怎麼判斷的：PowerShell 會被注入一小段提示字元標記，指令跑完時回報離開碼；
> 常駐型的代理 CLI（它一直沒退出）則看畫面有沒有在動——代理在忙時輸出不會停，停下來等你就是安靜的。

### CC 代理

集中切換 Claude Code 的供應商、MCP 與 CLI 版本。

- Grok、Codex、Ollama Cloud、OpenCode Go、Command Code、OpenRouter 六家內建供應商可各自選「上游格式」
- 轉換閘道是一顆手動開關，不會因切換供應商自行啟動
- 每家都有「測試」按鈕，送一個最小請求，只顯示是否收到回應與 HTTP 狀態，不顯示上游內容
- 內建端點由 App 固定，只有自訂供應商可填 Base URL；Codex／Grok 可沿用 CLI 登入或在 App 登入
- **宣告支援 1M 上下文**：勾選後四個等級的模型名會補 `[1m]`，Claude Code 就把上下文窗當成 1M
  （這是「宣告」不是「升級」——上游實際只有 372K 的話，講超過還是會被上游擋下來）

### HF模型（本機大型語言模型）

在 Hugging Face 上搜模型 → 下載 → 一鍵載入 → **直接出現在聊天的模型選單裡**。推論引擎是 llama.cpp。

- **探索**：左邊搜尋結果、右邊模型卡。點任一顆就看得到它的 README、下載數與更新日期、
  參數量與架構，以及**下載選項**——每個量化版本的大小旁邊直接標著「這台跑不跑得動」，
  **還沒下載就算得出來**（一個 repo 只抓一次檔頭前 1MB，不必先花好幾 GB 頻寬）。也可以直接貼 `owner/repo`
- **模型庫**：已安裝的模型一張卡，顯示架構、量化、參數量（MoE 另外標激活參數）、context 上限、多模態。
  載入／卸載、自動調參、改參數、刪除都是常駐按鈕。也可以自己把 `.gguf` 拖進模型資料夾再按「重新掃描」
- **自動決定參數**：偵測這台的顯示卡與可用顯存，決定上下文長度、GPU 層數、KV 快取量化檔位、
  執行緒、投機解碼；多模態自動掛上圖片解碼器；MoE 塞不下時把專家搬到 CPU 而不是砍層數。
  記憶體配置以官方 `llama-fit-params` **實際載一次模型量出來的**為準，不是估的
- **一鍵自動調參**：按下去就先用官方 `llama-fit-params` 實際載一次模型量記憶體，
  再用 `llama-bench` 實測比幾組候選參數，挑最快的直接套用
- **比 LM Studio 自由**：每一項自動決定的參數都可以覆寫（空著就維持自動，旁邊寫著自動值是多少），
  另有「原始參數」直通 llama-server 的任何旗標
- 模型放哪可以自己選（預設 `%APPDATA%/voiceink/hf-models/`）——30B 的 MoE 動輒 20GB，C 碟未必塞得下
- **推論後端一鍵安裝**：執行環境分頁按「一鍵安裝最佳配置」，
  有夠新的 NVIDIA 驅動就裝 CUDA 版（比較快），否則裝 Vulkan 版（任何現代顯卡都能跑）

### 額度儀錶板

集中查看 **Claude Code、Codex、Antigravity、OpenCode Go、Grok、Ollama Cloud、Command Code** 的已用額度與重置倒數。

- **只有按下「同步」才會連線**；啟動 App 與進頁只讀本機快取
- 卡片兩欄排列（窄視窗自動收成一欄），可直接抓著卡片拖曳排序：拖曳中卡片跟著游標且不會變半透明，其他卡片平滑推開，放開即歸位
- 鍵盤也能排序：Space 抓取、方向鍵移動、Enter／Space 放下、Esc 取消
- 訂閱方案（Pro／Max／Plus…）顯示在卡片底部，來源是本機登入檔而不是額度 API
- 可隱藏個別來源、拖曳調整卡片順序，並查看已去敏的來源診斷
- 同一頁另有**用量統計**子分頁：掃本機五家 CLI 的對話記錄，算出實際花掉多少 token 與美金
  （跟「訂閱額度」是兩件事），趨勢與分佈都把 token 拆成輸入／輸出／快取讀／快取寫

| 來源 | 取得方式 |
|---|---|
| Claude Code／Codex／Grok | 本機登入憑證 + 官方額度 API |
| Antigravity | Windows Credential Manager + Google cloudcode-pa，分列 Claude／Gemini 的 5 小時與每週視窗 |
| OpenCode Go | 官方 `zen/go/v1/usage`（5 小時／每週／每月三個百分比視窗） |
| Ollama Cloud | 官方 `api/usage`（每月用量；上游不提供重置時間） |
| Command Code | 官方 `alpha/billing/credits`＋`alpha/billing/subscriptions`（5 小時／每週／每月） |

憑證、原始 API 回應、任意 URL／路徑／SQL 都不會交給 renderer。

### AGY 反向代理

把本機的 Antigravity 登入憑證轉成標準 API，讓任何 OpenAI 或 Anthropic 相容的工具直接用。憑證由官方的 Antigravity CLI 或 IDE 維護，VoiceInk 只讀不寫。

- 雙協議入口：`/v1/chat/completions`（Cherry Studio、NextChat、Kilo Code…）與 `/v1/messages`（Claude Code CLI、CC Switch）
- **兩組 Base URL 分開列在頁面上**：OpenAI 相容工具要帶 `/v1`，Claude Code 要根位址（它自己會接 `/v1/messages`，多帶一層會變成 404）
- **可用模型**面板：直接查上游現在給得出哪些模型，排序由新到舊，點一下複製 ID
- **測試連線**：自動挑一個有額度的模型，從 loopback 真的送一則訊息，驗整條路而不是只 ping
- 模型映射：`claude-sonnet-4-5-20250929`、`gpt-4o` 這類上游沒有的名字會自動對應到實際模型，表外的原樣透傳
- **只監聽 `127.0.0.1` 且強制帶金鑰**，金鑰由 App 產生、可一鍵重產；並檢查 `Host` 擋 DNS rebinding
- 流量日誌與統計：可選 6 小時／24 小時／7 天／30 天／全部，統計卡、趨勢圖與模型分佈共用同一個時間範圍；滑過長條顯示該時段的請求數與 token；預設只記 metadata，另有除錯模式才記截斷後的內容
- 串流、工具呼叫、思考內容、圖片輸入都會轉換；上游限流會原樣把 429 與 `retry-after` 傳給客戶端

> 開著反代時，VoiceInk 自己的聊天頁新增一組供應商、URL 填 `http://127.0.0.1:8788/v1`，就能直接用 Antigravity 額度聊天。

### 語音轉文字

同一分頁裡三個子分頁，**每個子分頁各有一組自己的模型選單**（就在那一頁的最上面）：
要用哪一顆語音辨識模型、哪一顆 LLM，在做事的地方直接選，不必跑去設定頁。

三頁各存各的，改一頁不會動到另外兩頁——即時字幕想用快的 GPU 那顆、語音輸入想用輕的
CPU 那顆、檔案轉錄可以慢慢跑，本來就不該共用同一組設定。

#### 檔案轉錄

拖放音訊檔（MP3、WAV、M4A、FLAC、OGG、AAC…）即可轉錄。ffmpeg 串流解碼、28 秒一段，支援 **2 小時／100MB 以上**（上限 4 小時／200MB），不整檔塞進記憶體。完成後可直接翻譯、複製或存檔。

#### 即時字幕

擷取電腦正在播放的任何聲音（YouTube、會議軟體…），直接取 16kHz mono PCM，由 VAD 在自然停頓處切句後轉錄與翻譯——沒有固定 2 秒硬切，也沒有錄音重啟造成的音訊缺口。

結果顯示在**置頂懸浮字幕視窗**：可拖動縮放、字級 A±、透明度切換、雙語／僅翻譯切換、一鍵複製全部。狀態列的音量條可確認是否擷取到聲音。

#### 語音輸入

**按住鍵盤右邊的 Alt 講話，放開就把整理好的文字貼到你正在打字的地方**——不限於 VoiceInk，
瀏覽器、編輯器、聊天軟體都可以。快速點一下右 Alt 是「開始／結束」切換（適合長段口述），
錄音中按 Esc 取消。啟用後即使 VoiceInk 縮在系統匣也有效。

講話時螢幕底部會浮出一顆小藥丸告訴你「正在聽」，波形跟著你的音量跳動；左邊的 ✕ 是取消、
右邊的 ✓ 是講完了送出。它會自動跑到**滑鼠所在的那一面螢幕**，接上第二台螢幕也找得到。
萬一失敗（例如雲端模型不能用），錯誤就寫在這顆藥丸上——你人在別的程式裡，本來也看不到
VoiceInk 的提示。

轉出來的文字會先交給 LLM 整理：刪掉「嗯、呃、那個」這類贅詞與重複、補上標點、
把講顛倒的順序重排、在你明顯是在列項目時改寫成條列。整理用哪一顆模型自己選
（不整理／本地 Qwen3.5／任何一組雲端供應商的模型），語音辨識也是這一頁自己的選單。
整理服務連不上時會退回「沒整理過的原文」照樣貼給你，不會讓你講的話消失。

每一筆都留紀錄（原文＋整理後，可複製、可刪）。**個人字典**會自己長：同一個詞被整理模型
改成同一種寫法兩次以上，就收進字典，之後辨識完先直接替換，也會附在整理的提示裡。
自己手動加也可以，字典裡的每一筆都看得到、刪得掉。

### 翻譯與 TTS

雙欄輸入／譯文版面，輸入**不限字數**（自動分段、可中途停止），⇄ 一鍵交換語言，Ctrl+Enter 送出。譯文可用 Edge TTS 朗讀，五語語音選擇、語速 -50…100。

### 系統監控

四個子分頁，資料由一顆常駐取樣器提供（整輪約 0.3 秒，不是每次點都重查）。

- **總覽**：CPU／記憶體／磁碟／網路即時曲線，加上一整份硬體規格（主機板、BIOS、記憶體條、
  插槽、螢幕、音訊裝置…）。磁碟**按實體碟分開**列，健康度、通電時數、寫入總量與溫度走
  **免提權**的 NVMe 查詢——不必裝 CrystalDiskInfo，也不必按 UAC
- **處理程序**：依 CPU／記憶體／磁碟／GPU 排序，可強制結束
- **壓力測試**：CPU、GPU、記憶體、磁碟四種各自可跑，跑的時候旁邊四格顯示負載／功耗／溫度／轉速
- **風扇控制**：通用機殼示意圖 + 可拖點的轉速曲線，每條通道各自設下限與緊急全速溫度；
  有「識別」鈕把指定通道拉到 100% 幾秒，用聽的認出是哪一顆

> 溫度、功耗、轉速這幾項要一顆**提權的感測器元件**（進頁時會問一次 UAC）；不給也能用，
> 只是那幾格會空著。風扇接管另外有一條免 UAC 的路（註冊一次排程工作，之後開機自動接手）。
> 筆電多半改不了風扇——廠商用自訂 EC，沒有公開介面。

## 模型

語音與翻譯各有一顆小的（CPU 跑得動）與一顆大的（建議 GPU），另加一顆專用微調。
下面這幾顆是內建的；**要跑別的大型語言模型請用「HF模型」分頁**，那邊可以直接從 Hugging Face 下載任何 GGUF。

| 模型 | 量化 | 大小 | 用途 |
|---|---|---|---|
| **Qwen3-ASR 0.6B** | INT8 | 941 MB | 本地語音辨識，52 語（含國／粵／閩語），**CPU**，即時字幕預設 |
| Qwen3-ASR 1.7B | Q8_0 | 2.35 GB | 本地語音辨識，準確度更好，走 **GPU**（需一併安裝下面的執行環境） |
| llama.cpp 執行環境（Vulkan） | — | 34 MB | GPU 語音模型與 HF模型的執行檔；任何有現代顯卡驅動的機器都能跑，不需 CUDA |
| llama.cpp 執行環境（CUDA 13.3） | — | 537 MB | 同上，但 NVIDIA 卡上明顯更快（需驅動 ≥ 580）。可選，裝了會優先用 |
| **LinguaForge 0.8B** | Q4_K_M | 505 MB | 本地翻譯（繁中／英／日）專用微調，預設 |
| Qwen3.5 0.8B | Q4_K_M | 508 MB | 本地翻譯，通用多語，CPU 跑得動 |
| Qwen3.5 4B | Q4_K_M | 2.55 GB | 本地翻譯，品質最好（專名、年份都保得住），建議 GPU |

- 設定 → 本地模型一鍵下載（含進度、取消、刪除），存放於 `%APPDATA%/voiceink/models/`，可點擊直達資料夾
- NVIDIA 顯卡且 VRAM ≥6GB 可開 GPU 翻譯（cuda → vulkan → CPU 自動 fallback）
- 中文輸出自動轉繁體（台灣用語），兩顆語音模型都一樣
- **語音辨識不必設定 CPU/GPU**：0.6B 那顆只有 CPU（sherpa-onnx 的 Windows 套件是 CPU-only 編譯，執行緒自動決定），1.7B 那顆走 GPU；選了模型就決定了推論方式

## 設定

導覽最後一頁，左側分類 rail 一次顯示一區。設定頁只管**裝了什麼、怎麼推論、雲端端點填什麼**；
**要用哪一顆模型，在做事的頁面直接選**（選了立刻生效）：語音轉文字的三個子分頁各有一組，
翻譯與 TTS 頁在標題旁。

| 分區 | 內容 |
|---|---|
| 本地模型 | 依語音辨識／翻譯／執行環境分組的下載／刪除／開資料夾；本地翻譯用 CPU 還是 GPU（含一鍵安裝 CUDA 環境，全域生效） |
| 雲端模型 | 供應商清單（聊天與翻譯共用，可多組＋模型掃描＋每顆標「生圖」）、語音轉文字端點 |
| 語音朗讀 | Edge TTS 五語語音與語速，每個語音旁有**試聽**鈕 |
| 基本 | 深色／淺色主題、關視窗是否留在系統匣、開機自動啟動 |

AGY 反代的設定（開關、埠、金鑰、日誌保留天數）在它自己的分頁，不走一般設定。

## 介面

Aurora glass 視覺：深色為深灰綠底搭配冷藍／暖金光暈，淺色以淡藍／灰綠／米金對應。七個主頁與置頂字幕窗共用 12px 柔邊半透明 surface，支援 900px／560px 響應式版面與 `prefers-reduced-motion`。主視窗為 frameless，標題列與導覽合併。

導覽順序：**聊天（預設，終端機在同一頁）｜CC代理｜額度｜AGY反代｜語音轉文字（檔案轉錄／即時字幕／語音輸入）｜翻譯與 TTS｜系統監控｜HF模型｜設定**

## 技術棧

- **Core**：Electron 43.4.1、Node.js 22
- **前端**：Vite、Vanilla JS、HTML/CSS（無框架、無狀態管理、無動畫套件）
- **本地 ASR**：sherpa-onnx（ONNX Runtime，CPU int8）
- **翻譯**：node-llama-cpp（GGUF）／OpenAI 相容 chat completions
- **聊天**：OpenAI 相容 chat completions（SSE 串流）
- **額度**：Main-only provider adapters，七家全走官方端點（bounded HTTPS）
- **反代**：Node 內建 `node:http`（無 server 框架）；日誌與統計走 `node:sqlite`
- **TTS**：Edge TTS（需連網）
- **簡繁**：opencc-js（僅在偵測到簡體時才套詞彙表）

## 即時字幕流程

```mermaid
graph TD
    A[系統 loopback 音訊] --> B[AudioContext 直接取 16kHz mono PCM]
    B --> C{能量 VAD}
    C -- 未說話 --> X[保留 250ms pre-roll]
    C -- 停頓 360ms／最長 6s --> Q[語句佇列: 最多 2 句]
    Q --> E[低音量增益 → 本地 ASR（CPU 或 GPU）→ 轉繁]
    E --> T{翻譯設定}
    T -- 雲端/本地 LLM --> F[翻譯]
    T -- 不翻譯 --> G
    F --> G[過濾重複循環]
    G --> J[懸浮視窗顯示字幕]
```
